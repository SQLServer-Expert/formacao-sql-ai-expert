### Instalação do VS Code

**Link para download**:
[https://code.visualstudio.com/](https://code.visualstudio.com/)

Escolher System Installer (x64) para instalar para todos os usuários!

### Instalar as seguintes Extensões:
- **Python (Microsoft)**: Suporte principal ao desenvolvimento Python.
- **Pylance**: IntelliSense, validação e autocomplete do Python.
- **Python Environments**: Ajuda no gerenciamento de ambientes Python.
- **Azure Functions**: Criar, executar, depurar e publicar Functions pelo VS Code.
- **Azurite**: Emulador local do Azure Storage.
- **Azure Resources**: Login no Azure e navegação pelos recursos da assinatura.
- **SQL Server (mssql)**: Recomendada	Conectar e consultar o Azure SQL sem sair do VS Code.
- **JSON Crack**: Útil para visualizar JSON, mas não faz parte dos pré-requisitos.
- **Markdown Preview**: Útil para visualizar arquivos Markdown (MD).
